# Contributing / Mitmachen

Issues and pull requests are welcome. Issues und Pull Requests sind willkommen.

- Keep it small: one change per pull request, with a test where it makes sense.
- Standard library only for `server/` and `tools/`. No new runtime dependencies.
- Run `python3 -m pytest -q` before you open a pull request.
- Examples must stay fictional: no real businesses, no real prices, phone numbers or addresses.
- Docs in English and German, same content in both.
- This is a side project, answers can take a few days. See the "as is" note in the README.

Kurz auf Deutsch: kleine Änderungen, Tests laufen lassen, nur Standardbibliothek, Beispiele bleiben erfunden, Doku zweisprachig. Antworten können ein paar Tage dauern.
